# CPP-00 · Classes and streams

Command-line arguments, stream I/O, and the first steps in class design. Each exercise has its own Makefile.

## Exercises

| Directory | Exercise | Focus |
| --- | --- | --- |
| [ex00](./ex00) | Uppercase arguments | Convert command-line text to uppercase. |
| [ex01](./ex01) | PhoneBook | Store and search contacts from an interactive prompt. |

## Build and run

Run these commands from the repository root with a C++98 compatible compiler and Make.

```sh
make -C ex00
./ex00/megaphone "hello, world"
```

To build another exercise, pass its directory to `make -C`.
